# Типографика

Golos Text, межбуквенный интервал 0. Источник шкалы — `styles/typography.css`.

| Роль | Desktop | Mobile |
| --- | --- | --- |
| Название страницы | 40/48 | 32/40 |
| Заголовок крупного кейса | 32/40 | 28/36 |
| Заголовок раздела, вводный текст | 24/32 | 22/30 |
| Основной текст | 20/30 | 18/28 |
| Навигация | 18/26 | 16/24 |
| Подпись и примечание | 16/24 | 16/24 |

Цвета: основной #202020, вторичный #595959, примечания #666666. На белом фоне все превышают 4.5:1. Цвета текста внутри скриншотов не изменяются. Отключённые элементы навигации допускают меньший контраст.

Заголовки — Medium 500, основной текст — Regular 400, смысловое выделение — 600. Заголовки карточек главной сохраняют выбранный Regular. Не используйте opacity для ослабления информационного текста: задавайте семантический цвет. Не понижайте основной текст до размеров подписей на мобильных.
